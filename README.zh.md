# 纯对话（Pure chat）

中文 | [English](README.md)

一个用于纯对话的 DSH 组合包：可选的 **纯对话** 预设（联网搜索、网页读取、文件导出），外加清空上下文按钮和会话头部的「跳转到提问」。

| 功能 | 作用 |
|---|---|
| 纯对话预设 | 对话直接发给模型；没有系统提示词，也没有宿主工具。 |
| `web_search` / `web_fetch` | 联网搜索，或把指定 URL 抓取为文本。 |
| `write_file` | 把文本保存为 txt、md、doc、xls、pdf。 |
| 清空上下文 | 输入框按钮：模型从头开始，对话记录不变。 |
| 跳转到提问 | 会话头部下拉：跳到任意一条历史提问。 |

**三步上手**：新建会话 → 选 **纯对话**（其他系统显示 “Pure chat”）→ 直接提问。想查资料说“查一下 …”，要文件说“导出成 PDF”。

```sh
# npm 安装（包发布到 npm 后可用）
dsh plugin --profile web add dsh-pure-chat
# GitHub 安装（现在就能用）
dsh plugin --profile web add github:EonCosmos/dsh-pure-chat
```

## 功能

### 纯对话预设

预设按系统语言显示名称：中文系统是 **纯对话**，其他系统是 **Pure chat**。DSH 不会翻译用户自撰的预设元数据，所以插件在注册预设时直接按宿主语言选择文案，而不是写一个中英混搭的名字。

使用该预设的会话只会发送：你的消息、模型回复、工具调用及其结果，以及一条 DSH 为校验会话目录而必需的运行时提示（例如 `Current Working directory: "C:\..."`）。它收不到 Harness 身份、agent 指令、人格、技能目录、工具使用说明、沙箱与审批策略，也收不到任何子代理身份。

所有宿主级全局工具都被隐藏（包括宿主作用域挂载的 Agent Teams 工具），模型能看到的正好是预设自带的三个工具。

### `web_search` 与 `web_fetch`

- `web_search`：联网搜索，返回可选摘要和来源链接。
- `web_fetch`：把指定 URL 抓取为 markdown 或纯文本。

`web_search` 仅在所选模型路由有可用搜索 provider 时出现；`web_fetch` 走 HTTP provider，始终可用。

### `write_file`：导出文档

模型传入路径、完整内容，以及可选的格式：

| 格式 | 实际写出的内容 | 可用软件打开 |
|---|---|---|
| `txt` | UTF-8 文本 | 任意编辑器 |
| `md` | UTF-8 Markdown | 任意编辑器、DSH |
| `doc` | RTF 文档（`.doc`） | Word、WPS、LibreOffice |
| `xls` | SpreadsheetML 工作簿（`.xls`） | Excel、WPS |
| `pdf` | 真正的 PDF | 任意 PDF 阅读器 |

需要知道的规则：

- 文件写入**会话工作目录内部**；越出该目录的路径会被拒绝，缺失的父目录自动创建。
- `xls` 每行一条记录，单元格之间用制表符分隔（整行没有制表符时用逗号）；第一行作为表头，纯数字内容写成数值单元格。
- `pdf` 通过 DSH 的 Office 组件（`office-kit`）渲染同一份文档，中文能保留字体；没有该组件时会明确报错，而不是写出打不开的 PDF。
- 单次内容上限 4 MiB。

### 清空上下文

清空上下文是独立于三个工具的能力：它改变的是模型下一次读到的内容，而不是工具能做什么。

发送箭头左侧有一个小按钮，只在选用本预设的会话中出现。

1. 点击按钮，弹出确认对话框说明影响。
2. 确认后，模型从全新的上下文开始回答。

DSH 的模型历史来自会话的有序 **surface**：清空会追加一条合成的用户消息，用一次 surface 替换覆盖此前所有对话节点。日志保留全部事件，对话记录里每条消息原样不动，下一次请求只派生那条新消息——不会修改旧气泡，也不会多出新气泡。当前回合仍在生成时命令会拒绝执行；已经没有可清空的内容时会提示“已为空”。

同一操作也可以用 `/clear-context` 命令触发。

### 跳转到提问

会话头部有一个下拉按钮，列出当前已加载对话里每条提问的开头文字；选中一条，聊天区就滚动到那条消息。

- 每行显示轮次编号和提问的前 10 个字符，内容来自宿主自己的轮次导航投影，所以每条都能落到实际存在的消息上。
- 键盘可用：方向键移动、Home/End 到首尾、Esc 关闭、回车选中。
- 这是客户端功能，**所有会话**都会出现，不只是本预设。它取代独立的 `dsh-question-jumper` 插件：如果还装着，请移除那个 bundle。

## 实现要点

- **工具屏蔽**：预设在自己的作用域里挂载工具，并按名字拒绝全部宿主全局工具（`ctx.tools.restrict({ deny })`）；作用域内的注册不受影响。拒绝列表在**每次 `tools/change` 时重算**，因此之后注册的全局工具（后装插件、HMR 重载）同样会被隐藏。若注册表拒绝这条限制，预设会激活失败，而不是悄悄带着全部工具启动。
- **客户端一半**：patch 只插入以包名命名的宿主行（`pure-chat-host`），这行的插件同时按宿主语言注册预设。Web 客户端只会从"以包名命名的 profile 条目"发现 `dsh.client`，这一行才让清空上下文按钮进入页面；预设组合把作用域那一半挂载为 `dsh-pure-chat/preset`。
- **没有压缩**：不会重写或摘要对话；太长时请用清空上下文或新建会话。

## 环境要求

- DSH `>= 0.2.2-rc.5`（`engines.dsh`）。
- `web_search` 需要配置好的搜索 provider；`web_fetch` 不需要。
- PDF 导出需要 `office-kit`；`doc` 和 `xls` 不需要额外组件。

## 安装

从 npm（发布后可用）：

```sh
dsh plugin --profile <profile> add dsh-pure-chat
```

从 GitHub（现在可用）：

```sh
dsh plugin --profile <profile> add github:EonCosmos/dsh-pure-chat
```

本地开发：**Plugins → Add plugin → 本目录**，或 `plugin_manager` 的 `action: install_bundle`。

安装或更新后请**刷新页面**（客户端包要进入启动清单），然后**新建会话**——已有会话保留它启动时的组合。

## 限制

- **工具调用仍属于 agent 循环的工作。** 搜索与写文件都是模型工具调用，由循环执行；除此之外整个回合就是普通聊天。
- 工具说明段落随系统提示词一起被移除，模型只能依赖每个工具的简短描述。想让它搜索，明确说“查一下 …”。
- 对话很长时会超出模型上下文，没有自动压缩。
- `pdf` 需要 DSH 的 Office 组件。
- 预设是组合配置，不是安全边界：它控制模型被告知什么、能调用什么，不控制谁可以安装插件。

## 更新与卸载

Git 安装不支持一键更新：在 **Plugins** 里移除后重新安装。npm 安装可以直接在同一页面更新。

- 1.2.0 起包名是 `dsh-pure-chat`（原 `@local/dsh-pure-chat`）；安装前先移除旧行。
- 更新前创建的会话保留原组合。
