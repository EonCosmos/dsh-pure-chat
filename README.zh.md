# 纯对话（Pure chat）

中文 | [English](README.md)

一个 DSH bundle，增加一个可选的 **agent 预设**。使用该预设的会话会把对话直接发给模型——没有系统提示词，也没有文件、Shell、终端、技能、子代理、团队或目标工具——只暴露两个只读联网工具，方便模型查资料：

- `web_search`——联网搜索，返回可选摘要和来源；
- `web_fetch`——把指定 URL 抓取为 markdown 或纯文本。

## 使用方法

1. 新建会话。
2. 在输入框上方的预设控件（“新建会话”那一行）选择 **Pure chat (纯对话)**。
3. 直接提问。需要最新信息时，模型会调用 `web_search`（需要读具体页面时调用 `web_fetch`），然后基于结果回答。

预设会记录在会话里，重启后仍保持该行为。会话保留启动时使用的组合：更新本 bundle 后，请新建会话以获得新行为。

## 模型能看到什么

- 你的用户消息、助手回复、联网工具调用及其结果。
- 一条 DSH 为校验会话目录而必需的运行时提示，例如 `Current working directory: "C:\..."`。
- 两个联网工具的 schema（名称、描述、参数）。
- 会话选择的模型路由和推理强度。

不会收到：Harness 身份、agent 指令、人格、技能目录、常规工具使用说明、沙箱/审批策略，以及任何子代理身份。所有宿主级全局工具（包括宿主作用域挂载的 Agent Teams 工具）都会被 bundle 插件隐藏；预设只挂载这两个联网工具。

## 工具是怎么被隐藏的

预设在自己的作用域里挂载两个联网工具，并按名字拒绝全部宿主全局工具（`ctx.tools.restrict({ deny })`）。作用域内的注册不受这条掩码影响，所以联网工具照常可见；不能用 `allow: []` 代替，因为注册表会拒绝空过滤器。

- 拒绝列表在**每次 `tools/change` 时重新计算**，不是激活时的一份快照。因此之后才注册的全局工具——后装的插件、HMR 重载——同样会被隐藏。
- `run_code` 永远不写进拒绝列表，因为注册表为它保留了名字；本预设也没有挂载 PTC 执行器，所以它在这里同样不可调用。
- 如果注册表拒绝了这条限制，预设会**激活失败**，而不是悄悄变成一个拥有全部工具的 agent；对应的插件行会在 Plugins 里显示诊断信息。

## 限制

- **工具调用仍属于 agent 循环的工作。** 联网查询以模型工具调用的形式执行，由 agent 循环完成；除此之外，整个回合就是普通聊天。
- 工具说明所在的系统提示词段落被一并移除，模型只能依赖每个工具自身的简短描述。对于看起来像常识的问题，它可能不会主动搜索；如果没有搜，明确说“查一下……”即可。
- 没有挂载压缩（compaction），对话很长时会超出模型上下文；请新建会话或换用上下文更大的模型。
- 仅当所选模型路由有可用的搜索 provider 时，`web_search` 才会被允许；`web_fetch` 使用 HTTP provider，始终可用。
- 预设是组合配置，不是安全边界：它控制模型被告知什么、能调用什么，不控制谁可以安装插件。

## 环境要求

- DSH `>= 0.2.2-rc.5`，以 `engines.dsh` 声明。
- `web_search` 需要配置好的搜索 provider；`web_fetch` 不需要。

## 安装

从 GitHub 安装：

```sh
dsh plugin --profile <profile> add github:EonCosmos/dsh-pure-chat
```

本地开发时，也可以用 **Plugins → Add plugin → 本目录**，或
`plugin_manager` 的 `action: install_bundle`，`target` 填本包目录。

## 升级

Git 安装不支持一键更新，请用上面的安装命令重新安装。预设 id 仍是 `pure-chat`，已选择它的会话不受影响。

1.2.0 把包名从 `@local/dsh-pure-chat` 改成了 `dsh-pure-chat`。请先移除旧 bundle（**Plugins → 移除**）再安装，否则 profile 里会同时留下两行，同一个预设也会被声明两次。
